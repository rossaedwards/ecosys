# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities to: **security@aurphyx.casino**

Do NOT open a public issue for security vulnerabilities.

## Security Features

- Provably fair game verification
- Quantum-certified randomness
- Multi-layer encryption
- KYC/AML compliance
- Fraud detection systems
- Secure win lockdown
- SAGES security integration

## Responsible Disclosure

We appreciate responsible disclosure of security issues. We will:
- Acknowledge receipt within 48 hours
- Provide updates on progress
- Credit you (if desired) after resolution

## Security Best Practices

- Keep dependencies updated
- Use strong authentication
- Encrypt sensitive data
- Regular security audits
- Monitor for anomalies
