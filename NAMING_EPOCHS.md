## 2026-08-24 — ICX Scientific Name Correction

| Epoch | Name | Status |
|-------|------|--------|
| Previous | Soul Identity aXis (ICX) | **Archived** |
| Current  | **Identity Coherence aXis (ICX)** | **Canonical** |

Reason: “Soul Identity” was too narrow and mythically overloaded for the scientific aXis name. “Identity Coherence” better reflects the continuity, provenance, and coherence functions of the aXis while remaining compatible with SoulShot / SoulSync / BlissID vocabulary at the application layer.

All new standards and the consolidated TSLCA scaffolding use **Identity Coherence aXis**.

## Vibe Audio Naming (updated 2026-08-25 — CANON)

**Canonical full name:** Vibe Audio Standard and Protocol (VASP)

| Term | Scope | Notes |
|------|-------|-------|
| **Vibe Audio Standard and Protocol (VASP)** | The complete standard for the domain of Sound | Umbrella / full name |
| **Vibe Audio Standard** | The everything — the full 9-pillar standard itself | Core standard body |
| **Vibe Audio Protocol** | Services, tools, platforms, streaming, SaaS, and implementation layer | Subordinate to the Standard |

- Location: `ecosys/vasp`
- “VAP” is legacy. All new references use **VASP**.
- Standard = the complete definitional body. Protocol = the services/tools/SaaS layer that implements and transports it.

## 2026-08-25 — SIX Scientific Name Lock (Coherence Triad)

| Epoch | Name | Status |
|-------|------|--------|
| Previous (historical) | Sensorimotor Integration aXis (SIX) | **Archived** |
| Intermediate | Somatic Intelligence aXis (SIX) | **Archived** |
| Current | **Somatic Coherence aXis (SIX)** | **Canonical** |

Reason: Parallelism with Systemic Coherence aXis (SCX) and Identity Coherence aXis (ICX). The triad is now uniformly “Coherence”. “Intelligence” belongs to the fusion operator (SUXS-IFO / Audry), not to the individual aXes.

**Locked triad (2026-08-25):**
- SIX = Somatic Coherence aXis
- SCX = Systemic Coherence aXis
- ICX = Identity Coherence aXis

All pure-axis standards in `tslca/` (APS-TSLCA-SIX-001, SCX-001, ICX-001, IFO-001) and the abstract/intro are at Version 3.76 under this naming.
