What Is G-Code?

G-code, or geometric code, is the most widely used programming language for CNC (Computer Numerical Control) machines and 3D printers. It's a series of commands that tell a machine precisely where to move, how fast to move, and what path to follow. While a CAD program designs the part, a CAM program translates that design into the G-code that the machine's controller understands.

Core Concepts and Common Commands

G-code is a blend of geometric and "miscellaneous" commands. The codes are typically an alphanumeric format, starting with a letter followed by numbers.

G-codes (Geometric): These commands control the machine's movement. They are the "verbs" of the program, dictating the how and where.

G00: Rapid positioning. This tells the machine to move as fast as possible to a specific coordinate without cutting or extruding.

G01: Linear movement. This moves the tool in a straight line at a specified feed rate (speed).

G02/G03: Clockwise and counterclockwise arcs. These commands are used for creating circular movements.

M-codes (Miscellaneous): These commands control all the auxiliary functions of the machine, like turning on or off a spindle, a coolant pump, or an extruder.

M03/M05: Turn spindle on/off.

M104/M109: Set extruder temperature and wait for it to heat up.

A Simple G-Code Example

Here’s a taste of what a simple program might look like for a 3D printer:

G21 ; Set units to millimeters

G90 ; Set positioning to absolute

M104 S200 ; Start heating the extruder to 200°C

M140 S60 ; Start heating the bed to 60°C

G28 ; Home all axes

M109 S200 ; Wait for extruder to reach 200°C

M190 S60 ; Wait for bed to reach 60°C

G1 Z20 F3000 ; Move Z axis up 20mm at 3000mm/min

G1 X0 Y0 F3000 ; Move to the start position (0,0)

G1 Z0.2 F1200 ; Move down to 0.2mm above the bed

G1 X100 Y100 E10 F1200 ; Extrude 10mm of filament while moving to (100,100)

M107 ; Turn off the fan

M84 ; Disable motors

 

 

How to Start Writing G-Code

You can write G-code by hand, but it's most effective for simple, small parts. The real magic happens when you use Computer-Aided Manufacturing (CAM) software, which translates your CAD designs into the complex G-code automatically. This is the way to go for any intricate part you have in mind.
