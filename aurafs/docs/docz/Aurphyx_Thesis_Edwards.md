## APPENDIX A: MATHEMATICAL SUPPLEMENTS

### A.1 Completely Positive, Trace-Preserving Maps

A quantum channel $\\mathcal{E}: \\mathcal{B}(\\mathcal{H}\_A) \\to \\mathcal{B}(\\mathcal{H}\_B)$ is CPTP if:

1. **Linearity:** $\\mathcal{E}(\\alpha \\rho + \\beta \\sigma) = \\alpha \\mathcal{E}(\\rho) + \\beta \\mathcal{E}(\\sigma)$
2. **Positivity:** $\\rho \\geq 0 \\Rightarrow \\mathcal{E}(\\rho) \\geq 0$
3. **Trace-preserving:** $\\text{Tr}\[\\mathcal{E}(\\rho)] = \\text{Tr}\[\\rho]$

**Kraus representation theorem:** Any CPTP map admits Kraus decomposition:
$$\\mathcal{E}(\\rho) = \\sum\_k E\_k \\rho E\_k^\\dagger, \\quad \\sum\_k E\_k^\\dagger E\_k = I$$

### A.2 Non-Semisimple TQFT Categories

Standard topological order is described by modular tensor categories (MTC), which are **semisimple**. Non-semisimple categories allow:

1. **Negligible objects** (zero quantum dimension)
2. **Projective modules** (partial entanglement)
3. **Logarithmic CFTs** (non-rational central charges)

**Neglecton example:** In the $(s\\ell(2), 2)$ category at level $k=2$, there exists a negligible object $\\omega$ with $d\_\\omega = 0$ but non-zero braiding properties. Its presence enables universal quantum gates beyond standard anyonic braiding.

### A.3 Integrated Information Calculation

For partition $P = {S, \\bar{S}}$ of system into parts $S$ and $\\bar{S}$:

$$\\text{MI}(S : \\bar{S}) = S(\\rho\_S) + S(\\rho\_{\\bar{S}}) - S(\\rho\_{S\\bar{S}})$$

where $S(\\rho) = -\\text{Tr}\[\\rho \\log\_2 \\rho]$ is von Neumann entropy.

Integrated information:
$$\\Phi(\\rho) = \\min\_{P} { \\text{MI}(S : \\bar{S}) }$$

For maximally entangled $n$-qubit GHZ state: $\\Phi = n-1$ bits.
