# Fuxyez Configuration Templates

This directory contains example mirrored configuration files for different Fuxyez extension types.

## Files

- **default.xuf** - Default configuration for pure `.fux` files
- **rust_bridge.srxuf** - Rust FFI bridge configuration for `.fuxrs` files
- **python_env.ypxuf** - Python integration configuration for `.fuxpy` files
- **oracle_schema.zey** - Oracle meta configuration for `.yez` files

## Usage

Copy the relevant template to your project and customize as needed. The compiler will automatically load mirrored configs when present.
