**Network Behavior**

**History & Audit**

- `GET /ledger/event``/:``event``_id`

  - Fetches full event details, validation trail.

- `GET /ledger/``events?limit``=50&cursor=...`

  - Paged retrieval of event DAG, hash-linked order, conflict orphans.

- `GET /ledger/votes``/:``validator``_id`

  - Per-validator past voting record.

**Real-time Event Streaming**

- **WebSocket:** `/``ws``/events/`

  - Streams finalized events, voting rounds, validator changes, with filtering support.

- **Server-sent events endpoint:**

  - `/stream/votes`, `/stream/finality`, `/stream/slashing`.

**Metrics & Monitoring**

- `GET /metrics/``prometheus`

  - Returns Prometheus-compatible counters, gauge stats (finiality lag, round times, slashing counts).

- `GET /dashboard/status`

  - Summarized operational health: consensus round, fork detector, backlog.

**Admin (POST with RBAC Authz & Rate Limit)**

- `POST /admin/``view_change`

  - Triggers manual view/leader transition.

- `POST /admin/slash`

  - Force penalty/out for malicious validator.

- `POST /admin/rotate`

  - Triggers explicit leader rotation (argument: validator_id).

- `POST /admin/validator/``update_weight`

  - Adjusts voting weight for given validator.

**Authorization & Trust Layers**

- All `/admin` endpoints require JWT auth with consensus-modifier role, signed and rate-limited per org or identity.

- `/consensus/*`, `/ledger/*` read APIs require read-only bearer or API key.

- Prometheus endpoint is IP whitelist or integrated with platform SSO (e.g., OIDC).
