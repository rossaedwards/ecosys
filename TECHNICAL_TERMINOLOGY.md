# Technical Terminology

Welcome is the human product map: [`aurphyx_welcome2tribe.md`](aurphyx_welcome2tribe.md). Physics names: [`SCIENTIFIC_TERMINOLOGY.md`](SCIENTIFIC_TERMINOLOGY.md).

## Core systems

**Aura** — Soul Operating System (personal). Not “AuraOS” in new prose.

**Egophyx** — Pro-existence governance OS. **Arora** — IOT / edge / embedded. **Biznyx** — enterprise OS.

**Audry** — Aura's soul, AdminMate, SAGES liaison.

**AuraFS** — filesystem, storage, mesh. Own product rules live under `aurafs/`.

**Fuxyez** — symbiotic quantum language. Host: Rust. FuxRT, YezRT, FUTE, YezL.

**g0dm0d3** — frame, control deck, orchestration. Desktop options: LDE, **SLIDE**, **Aura-HDE**.

**Memoree** — TSLCA memory architecture. Must install with g0dm0d3-core or g0dm0d3-ktrl.

**VASP** — Vibe Audio Standard and Protocol. Vibe is audio. APS-OKF is not Vibe.

**SAGES** — 13 guardians. Governance field: Spaces · Manifolds · Dimensions · Vectors · Tensors · Layers · Channels · Lattices · Cores · Nodes · Shards.

**Xessability** — current term for retired “Accessibility” in SUXS.
